# Submission Checklist — World Cup Cities Hack (Rice University Urban Sustainability Hackathon)

Deadline: **September 17, 11:45pm CDT.** Submit with hours of buffer, not minutes — video upload/processing and Devpost's own submission form can both take longer than expected right at a deadline.

## 1. Code (this week)
- [ ] Decide the "All Possibilities" highlighting question, apply if wanted.
- [ ] Run the bug-fix / accessibility pass (prompt below).
- [ ] Stop adding features after that — freeze the app.

## 2. Pitch deck
- [ ] Fill in `[Your Team Name]` on slides 1 and 13.
- [ ] Replace the three SCREENSHOT placeholders on slide 9 with real screenshots of the running app (Compare Cities, Optimizer, Map).
- [ ] Optional: swap in your actual team member names/roles if the hackathon wants them on a slide.

## 3. Demo video
- [ ] Record following `Demo_Video_Script.md`, ≤ the hackathon's stated time limit (verify it — commonly 3 minutes for Devpost hackathons).
- [ ] Upload to YouTube or Vimeo as **unlisted**, not private.
- [ ] Test the link in an incognito/private window before submitting — a judge without your login must be able to open it.

## 4. Devpost submission page
- [ ] Project title and one-line tagline.
- [ ] Elevator pitch (2–3 sentences) — pull straight from slide 1's subtitle.
- [ ] Full write-up: inspiration, what it does, how you built it, challenges, accomplishments, what's next. The pitch deck's slide content maps directly onto these sections — reuse it rather than writing from scratch.
- [ ] Tech stack tags: Next.js, TypeScript, Tailwind, TanStack Query, ECharts, MapLibre GL, FastAPI, Python, scipy (MILP/HiGHS), Pytest, Vitest.
- [ ] 3–5 screenshots uploaded (same ones you used in the deck).
- [ ] Demo video link embedded.
- [ ] GitHub repo link — **check it's public, or that judges are added as collaborators**, before submitting. A private repo a judge can't open is a common, avoidable disqualifier.
- [ ] Correct track selected: Track 1 — Transportation & Access.
- [ ] All team members added to the submission on Devpost (not just you).

## 5. Final pass
- [ ] Open the live Devpost submission page once it's live and click every link yourself (repo, video, any external source links) — confirm none 404.
- [ ] Submit, then confirm you received Devpost's confirmation (email or on-page).
